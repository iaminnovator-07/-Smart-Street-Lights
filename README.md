# 🌃 Smart Street Lights

An Arduino-based smart street lighting prototype developed to explore automation, energy efficiency and sensor-controlled lighting systems.

━━━━━━━━━━━━━━━━━━
🚀 Overview
━━━━━━━━━━━━━━━━━━

Smart Street Lights was an early embedded systems project focused on understanding automation logic using sensors and microcontrollers.

The system automatically controls street lights based on environmental conditions and movement detection to reduce unnecessary energy consumption.

⚙ Working Principle
━━━━━━━━━━━━━━━━━━

The system uses an LDR sensor to detect ambient light conditions.

During low-light environments:
• street lights activate automatically

Using IR/motion sensing:
• lights can brighten when movement is detected

This helps reduce unnecessary power usage and simulates an intelligent street lighting system.
